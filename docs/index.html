    How to read this dashboard

    Risk score (0–100)

    35% CVSS (scaled) + 40% EPSS (probability of exploitation in the next 30 days) + a 25-point bonus when the CVE is in CISA's Known Exploited Vulnerabilities catalog, capped at 100. Real-world exploitation is weighted above theoretical severity.

    If CVSS or EPSS is not published yet, its weight is redistributed across the known components instead of scoring zero, so missing data never reads as "safe". Open Score breakdown on any card to see the exact math.

    Data integrity

    Every external API response is schema-validated before use. On an unexpected shape the pipeline logs a warning and skips that data rather than guessing. The score is a local triage heuristic, not an industry standard. Use it to decide order, not as a sole go/no-go gate.

    Data refreshes about every 4 hours via GitHub Actions. A red banner appears above if the last update is more than 20 hours old.

    Feeds & integration

    • RSS feed and JSON feed: new CISA KEV entries
    • data/alerts.json: the full dataset
    • JSON Schema (Draft-07) for validating integrations

    Reviewed marks and saved views live only in this browser. Use Triage → Export to move them.
