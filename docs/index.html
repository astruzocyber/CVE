Risk score (0-100) = 35% CVSS (scaled) + 40% EPSS (probability of exploitation in the next 30 days) + 25% flat bonus if listed in CISA's Known Exploited Vulnerabilities catalog, capped at 100. This weights real-world exploitation signal above theoretical severity and is a local heuristic, not an industry-standard score -- use it to triage order, not as a sole go/no-go gate. Every external API response is schema-validated before use; on an unexpected shape the pipeline logs a warning and skips that data rather than guessing.
